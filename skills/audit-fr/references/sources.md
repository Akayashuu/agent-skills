## Règle de citation dans un rapport

1. Citer Légifrance pour un numéro d'article.
2. Citer Service-Public / CNIL / France Num / accessibilite.numerique.gouv.fr pour la lecture pratique.
3. Si Service-Public et Légifrance divergent (cas F37351 / art. 6), Légifrance gagne. Le noter dans le rapport.
4. Ne pas citer un cabinet, un SaaS juridique, ni un blog.
